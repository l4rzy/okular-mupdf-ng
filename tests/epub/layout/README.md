# Original EPUB layout fixtures

`middle.epub` and `top.epub` are two-chapter EPUB 3 books generated by
`python3 tests/epub/layout/generate.py` using only Python's standard library.
Each is approximately 117 KiB. ZIP entry order, timestamps, and permissions
are fixed so regeneration is reproducible.

Both combine an original PNG diagram, inline image alignment, a following
caption and paragraph, an image inside a bordered table, a table caption,
an embedded heading font, a navigation document, and reciprocal chapter links.
They differ in `vertical-align: middle` versus `top`. They contain no material
from commercial books. The original text, graphics, and generator are licensed
under the repository's GPL-3.0-or-later license (copyright 2026 l4rzy).

The unmodified Allura font comes from `thirdparty/allura/Allura-Regular.ttf`.
It is Copyright 2010 The Allura Project Authors and licensed under the SIL Open
Font License 1.1. Each EPUB includes the font's complete `OFL.txt` license.

`test_generator_epub` loads the actual Okular plugin and exercises:

- Cold opening, text extraction, rendering, chapter links, and outline loading.
- Persistent accelerator and outline creation, followed by reopening with the
  cache populated. A distinguishable cached title proves outline reuse; text
  and bounding boxes must match the cold session.
- Asynchronous PDF export in both sessions, waiting for completion.
- Exported images and Allura glyphs, with no image/actual-text overlap.
- Reopening each exported PDF through the plugin, rendering both pages, and
  checking complete text, chapter links, and the original outline titles.

All cache, configuration, and exported files are isolated in a temporary root.
The fixture EPUBs are never modified by the tests.

`rem.epub` is a small two-chapter book generated deterministically by
`python3 tests/epub/layout/generate-rem.py`. Its original text and generator
use the same GPL-3.0-or-later license and copyright as the fixtures above.
It contains no embedded fonts or material from commercial books. Chapter roots
use 85% and 125% font sizes; paragraphs and headings use `rem`, list items
inherit, nested elements distinguish `rem` from `em`, and fixed text uses `pt`.
The plugin tests open it at two configured sizes and compare cold/warm text
geometry, chapter navigation and exported PDF font sizes before reopening.
